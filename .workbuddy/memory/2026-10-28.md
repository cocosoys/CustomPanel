- `IPanelActionService` + `execute(Long actionId, ActionExecuteRequest, CredentialPresentation)` 契约（javadoc 定死三分派）。
- `PanelActionServiceImpl`：
  - 构造注入 `CustomPanel plugin`（PanelExpansion 已改为 `new PanelActionServiceImpl(plugin)`）——COMMAND 需 Bukkit scheduler。
  - `execute` 分派：COMMAND / HTTP / INTERNAL，未知类型报 `type-invalid`。
  - **COMMAND**：`Bukkit.getScheduler().runTask(plugin, () -> Bukkit.dispatchCommand(Bukkit.getConsoleSender(), cmd))`，`{fieldKey}` 占位插值（记录 dataJson 键值 + 请求 params，params 同名优先）。
  - **HTTP**：`CompletableFuture.runAsync` 中经 `HttpOverMcPlugin.getInstance().getApi().getHttpClient().sendHttp(method,url,null,null)`；同步阶段仅协议校验（http/https）+ 字面量环回拦截（localhost/127.0.0.1/0.0.0.0/::1 → `http-url-blocked`）；异步阶段 DNS 解析级 SSRF 防护（`InetAddress` 环回/链路本地/站点本地/10/172.16-31/192.168/169.254 → 拒绝并记 warn 日志）。
  - **INTERNAL**：异步线程 `sendApi(method, logicalPath, null, null)`（本地分发，绕网络但注解权限照常生效）；目标必须 `/` 开头。
  - 目标格式 `METHOD URL`（无方法前缀默认 GET；非法方法头回退 GET）；`splitMethodTarget` 解析。
  - dataJson 解析用 SOYS `JsonReader.parseObject`（零依赖反序列化器）。
  - `httpClient()` 帮助方法：SOYS 未就绪返回 null，调用方按空处理。
- `PanelActionController`：`@PostMapping("/execute/{actionId}")` + `@ApiPermission("custompanel:action:execute")` 一行委托。**SOYS `@RequestBody` 注解没有 required 属性**；空 body 时网关 `JsonReader.fromJson("", type)` → 空实体（不 400），故直接 `@RequestBody ActionExecuteRequest` 即可。
