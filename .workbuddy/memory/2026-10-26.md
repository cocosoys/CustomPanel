## 架构要点（后续开发依赖）

- SOYS 侧入口：`SoysExpansion` 抽象基类 —— `register()` 骨架自动完成
  端点登记(`/api/plugins/<插件名>/*`)、页面托管(`/web/plugins/<插件名>/*`，`resourceRoot()`)、
  数据层初始化(`dataRoots()/sqlRoots()/seedData()/schemaVersion()`)、CORS、冲突检测与失败回滚。
- MCERP 侧入口：`McerpExpansion extends SoysExpansion`（软依赖需先探测再加载类，避免 NoClassDefFoundError）。
  覆写 `displayName()/icon()/sortOrder()/menus()/wujie()`，一行 `register()` 即进 ERP 侧边栏。
  菜单 DSL：`ErpMenus.create().dir(...).menu(...)`，`ControllerPermScanner` 可从 Controller 的
  `@ApiPermission` 自动投影 F 按钮。
- 前端契约：`public/__SOYS_CONTEXT__.js` 注入 `apiFullPrefix` / `pageFullPrefix`，
  前端 vue-router 用 history 模式 + base 取 `pageBase`；`SOYS_CONTEXT_EXCLUDES` 需排除 `/prod-api`、`/api`。
- 参考范例：`SOYSMonthlyCard/src/main/java/soys/soysmonthlycard/erp/MonthlyCardErpExpansion.java`
  （iframe 模式、pageRoot 覆盖为 owner 插件名、三 Controller 登记）。
- `SOYSHTTPOverMC-ERP/` 只有前端 `RuoYi-Vue2-master/`，无 Java 源码，不可作为后端参考。
