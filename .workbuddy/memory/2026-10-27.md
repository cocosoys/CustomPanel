## SOYS 开发规范（已核实）

- **spring 分层**（SOYS 自身即是此结构）：`spring/entity`、`spring/entity/vo`、`spring/service`（接口）、
  `spring/impl`（实现）、`spring/controller`。
- **API 注解包**：`com.github.cocosoys.mc.soyshttpovermc.annotations`
  - 类级 `@RequestMapping("/system/user")`；方法级 `@GetMapping/@PostMapping/@PutMapping/@DeleteMapping/@PatchMapping`
  - 元信息 `@ApiName("中文名")`；鉴权 `@ApiPermission("mcerp:system:user:list")` 或 `@ApiPublic`
    （⚠️ 既无 Permission 又无 Public 的端点网关默认 403）
  - 参数 `@RequestParam(name=,required=)` / `@PathVariable(name=)` / `@RequestBody`；可注入
    `CredentialPresentation credential`（web.gateway.policy.auth.issuer 包）
  - 其他：`@Hidden`、`@Deprecated`、`@Anonymous`、`@RateLimiter`、`@RepeatSubmit`
- **响应体**：`AjaxResult`（success()/success(obj)/error(msg)/put(k,v)）；
  分页必须返回 `TableDataInfo`（extends AjaxResult，平铺 code/msg/rows/total，前端按 rows/total 渲染）。
  分页辅助 `PageUtils.page(list, pageNum, pageSize)`。
- **Controller 铁律**：只做参数绑定 + 权限声明，方法体**一行 `return service.xxx(...)`**，零业务逻辑。
- **实体**：继承 `com.github.cocosoys.mc.soyshttpovermc.spring.entity.BaseEntity`
  （createTime/updateTime 落库 + createBy/updateBy/remark/params 为 `@TableField(exist=false)`）；
  ORM 注解在 **`com.dlz.db.annotation`**：`@TableName("erp_user")`、`@TableId(type = IdType.AUTO)`、`@TableField(exist=false)`。
- **存储门面 `com.github.cocosoys.mc.soyshttpovermc.orm.DATA`**（无需自行实现持久化）：
  - 读：`select(Class)` / `select(Class, Consumer<Query<T>>)` / `selectW(Class)` 条件链 / `get(Class,id)` /
        `selectPage(Class,current,size)` → `Page<T>` / `search(Class,keyword,fields...)` / `searchPage(...)`
  - 写：`insert(T)` / `updateById(T)` / `deleteById(Class,id)`
  - 运维：`ensureTable(Class)` / `count(Class)` / `clear(Class)` / `upsertAll` / `mergeAll` / `sqlEnabled()` / `primaryType()`
  - 单主路由：MYSQL(30) > SQLITE(20) > YAML(10)，SQL 可用走 SQL 否则 YAML；双不可用抛 IllegalStateException。
- **日志**：`@CustomLog`（Lombok 自定义日志）+ 项目根 `lombok.config`：
  `config.stopBubbling = true` + `lombok.log.custom.declaration = <LogKit全类名> <LogKit全类名>.getLogger(TYPE)`；
  LogKit 继承 `com.github.cocosoys.mc.soyshttpovermc.log.LogKit`，提供 `log.infoT(key, fallback, args...)`。
  MCERP 范例：`McerpLogKit extends LogKit`，前缀 `[MCERP]`。
- **i18n**：`I18n.resolve(key, fallback, args...)`；插件可注册自己的语言包（MCERP：`McerpI18n.register(this)` +
  `resources/language/zh_cn.yml`）。
- **按钮自动投影**：`ControllerPermScanner.scan(Controller.class)` 把端点方法按 `@ApiName/@ApiPermission`
  投影为 F 按钮菜单节点；`@ApiPublic` 不设权限、`@Hidden` 跳过、无权限声明的端点不生成按钮。
  经 `ErpMenus.menu(name, title, icon, Controller.class)` 或 `.permsFrom(Class...)` 接入。

  `pageRoot()`/`pageDirRoot()` 自动生成 `/web/plugins/<插件名>[/安全目录名]` 前缀。

## 关键架构约束（待用户确认）

⚠️ **SOYS ORM 要求编译期实体类**（`@TableName` + `PojoMeta` 反射），
**运行时动态建表/动态字段无法直接映射 ORM 实体**。因此「配置驱动」的业务数据有两种落法：
- A. **通用行存储**：`PanelRecord(pageId, recordId, dataJson)` —— 任意页面配置都能存，但无列级索引/条件查询；
- B. **预置实体托管**：新增数据表仍需写代码建实体 —— 查询能力强，但"零代码扩展"打折；
- C. **混合**：页面可切换「托管模式（绑定已有实体）」/「自由模式（通用行存储）」。

## 用户确认的三项决策

1. **数据落法 = 混合（托管 + 自由）**：`PanelPage.storeMode` = MANAGED（绑编译期实体）/ FREE（通用行存储）。
2. **渲染模式 = wujie 微前端**（`wujie()` 返回 true，默认）。
3. **首期范围 = 骨架优先，分步验证**：先跑通一条完整链路再批量铺开。

## 踩坑

- **同一文件的两个 Edit 不能并发提交**：并行发往同一文件时后写的会覆盖先写的，导致"部分改动静默丢失"（本次 PanelPageServiceImpl 的字段声明 + PanelExpansion 的 import 块各丢一次）。同一文件必须串行编辑。
- **RCON 鉴权成功返回空载荷**，失败的标志是服务端回发 `requestId = -1`；不能拿"响应文本为空"当失败判据。
- MCERP 实体（ErpUser/ErpDictData 等）同样在继承 `BaseEntity` 后自行声明 `private String remark` 覆盖 `exist=false` 的父类字段，本插件沿用该写法无冲突。
- 分页：先全量 `DATA.select` → 过滤 → `PageUtils.page(rows, pageNum, pageSize)` 返回 `TableDataInfo`。
- `BaseEntity.remark` 是 `@TableField(exist=false)` **不落库**；实体需自己显式声明 `remark` 才会入库。

### 踩坑（本轮新增）

1. **PowerShell 调 curl.exe 传 JSON body**：参数中双引号被 PowerShell 剥离 → 服务端
   "请求体 JSON 解析失败: 期望字符串"。**改用 Invoke-RestMethod + ConvertTo-Json 最稳**。
2. **PowerShell 函数输出捕获**：`$r = Show ...` 会把函数内所有 Write-Output 吞进 $r，
   导致返回结构污染（$r[0] 是标题而非 "OK"）。**函数内打印用 Write-Host，return 才进管道**。
3. **PowerShell 字符串插值**：`$id (` 会被解析为非法变量引用 → 用 `${id}` 或字符串拼接。
4. **中文版 .ps1 乱码**：Write 写 UTF-8 无 BOM，pwsh 读取出现 "娴嬭瘯" 乱码 →
   验证脚本测试数据改用 ASCII 文本最稳；中文文案已由 jar 内 yaml + HTTP 返回体验证。
5. **urllib 的 UnicodeEncodeError**：沙箱 python 的 http.client 对含中文 body 编码异常，
   弃用 urllib 做 HTTP 验证，改 Invoke-RestMethod。
